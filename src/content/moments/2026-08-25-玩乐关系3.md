「啊，对、对了。说起来，米芙露小姐小时候的梦想，到底是什么啊？」 \
「诶!?　「哎呀，那个，那个嘛……怎么说呢，也、也没必要非讲不可吧……」 \
「？不过说起来，你刚才是不是也在故意岔开话题啊。还说什么不够符合时代、很羞耻之类的。」 \
「呜。那、那倒也是。所以别再追着问啦。」 \
「嗯——可我觉得，聊将来梦想这种事，本来就是连这些部分一起才会热闹啊。桌游里的‘剧情式’也是，比起顺顺利利的时候，闹成大型惨案的时候反而更嗨吧。更别说你喜欢的那种派对游戏了，不也是参加的人稍微出点糗、丢点脸，才特别有意思吗？」 \
「呜哇，居然被桌游宅拿人际交流那套道理给说赢了。太屈辱了。」 \
「你这说法对我来说也很屈辱好吗。」 \
　为什么我们俩总是除了互相伤害以外什么都不会啊。真的。 \
　就在我唉声叹气的时候，米芙露小姐像是稍微下定了点决心似的，开口了。 \
「可、可是可是，这事说出来真的会变成大型惨案哦？番长，你做好心理准备了吗？」 \
「哈哈，什么啊这是。你都这么吊我胃口了，那我当然只能听了吧。」 \
「要、要我说到那个份上……我、我是可以说啦。可、可要是气氛变奇怪了，那、那都得怪番长你！呜呜……」 \
米芙露小姐在那里不知嘟囔着什么。也多亏她先乱了阵脚，我这边反倒总算慢慢冷静下来了。 \
「好好好，所以，米芙露小姐小时候的梦想，到底是什么啊？」 \
　我重新问了一遍，同时回头看去。 \
　然后，就看见……刚才还像面纱一样罩在头上的毛巾，被她用双手紧紧攥着，满脸羞意。脸颊红得通透……站在那里的是个羞得快要原地蒸发的辣妹同事。 \
　接着，她就带着那种简直像纯情少女本人一样的气息，小小声地说出了那个「梦想」。 \
「我……想当……新娘子。」
