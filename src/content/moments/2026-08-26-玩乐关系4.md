「羽切的权势也好，财产也好，我都会全部交给你。令妹的手术费想必也能毫无问题地筹出来，这样一来，你一直打从心底渴求的那种名为‘人格受到认可’的荣誉，想必也能到手吧。只不过，说是交换条件也许不太好听──」 \
　──唯独我，羽切菜摘，永生永世都不会属于你。还请你先明白这一点。 \
　那一天，菜摘妖冶地微笑着说出这番话时的──菜摘小姐的脸，到现在我都还记得清清楚楚。 \
　老实说，当时我脑子里只有一句「这人到底在说什么鬼东西」。要说这是契约，我这边付出的代价也未免太轻了，轻到我甚至都怀疑过她是不是在诈骗。可拿我这种人设局行骗，谁都捞不到好处。于是我还是接受了，然后──漂亮地把一切都拿到手了。 \
　入赘羽切之后，我的人生简直顺风顺水得不能再顺风顺水。说到底，是因为羽切菜摘那种「赋予别人角色」的才能，和我这种「见什么场合就变成什么样」的性子，契合得出奇地好。起初我还担心，名门望族那套社交场我这种人真能跟得上吗，可真进去了才发现，也不过如此。 \
　那里，根本就是个薄得发空、专门为我这种人量身打造的匣庭世界。 \
　我对羽切菜摘，真是怎么感激都不够。虽然在人前我会直接把她当妻子那样叫「菜摘」，可在心里，我直到现在都还会不自觉地叫她一声「菜摘小姐」——她对我而言，真的是恩人。 \
　不管是替小鸟游家抬高门第，还是劝我去当老师，教我该怎么讨好岳父岳母，再到──救了我妹妹。桩桩件件，对我来说都像是瞌睡来了就有人递枕头。 \
　而且最妙的是──她甚至连我在外头偷吃都很宽容。 \
　毕竟契约都已经是那样了，所以她的态度就是，我在外面玩女人这件事本身，她根本无所谓。对向来忠于欲望的我来说，这待遇简直好得过头了。当然，顾及羽切家的脸面，她也确实告诫过我，别把事情闹得太张扬太难看，但也就仅此而已。 \
　说到底啊——对我来说，羽切的匣庭曾经就是天堂。 \
　那是个没有半点痛苦的天堂。……本来应该是这样的。 \
　直到某个蠢得无可救药的意外，偏偏发生了。 \
「久等了。」 \
　回过神时，菜摘小姐不知什么时候已经走到了我的面前。看来，她和米芙露的对话已经结束了。 \
　她睁着那双圆润有神的眼睛望着我——不，是望着「僕」，然后嗤嗤地笑了出来。 \
「怎么啦，居然发起呆来了，一点都不像你。真好笑。」 \
「没、没有……」 \
「真乖呢，知道自己的身份，也肯老老实实等着。」 \
　又被她用老一套的话夸了一句，我也还是和往常一样，听得一阵不爽。 \
　她那句口头禅般的「真乖呢」，说白了，其实更接近「good　boy」的语感。在美国，这话既可以拿来夸小孩或宠物，可要是对成年男人说，多少就带了点故意逗弄、甚至挑衅的味道。 \
　所以，她拿这句话对常盘孤太郎说时，勉强还算是在夸人；可一旦是对我——羽切臣虎说，那里面就明显带着轻蔑。……真是句设计得恰到好处的口头禅。 \
　我正想着这些，心里烦得要命，她却又接着说了下去。 \
「啊，不过话说回来……」 \
　她低声这么一说，便转身背对着我。随后，她把脸转向了那个人所在的方向……转向常盘孤太郎所在的那一边，又一次提起了那个「老话题」。 \
「也不知道孤太郎现在在做什么呢。」 \
　你看，又来了。她从来不会跟眼前的我说话，她嘴里说的永远都是远处的那个他。也正因为这样，我有时甚至会恍惚，以为自己真的就是「常盘孤太郎」。……可我这样的货色，又怎么可能代替得了那个耀眼到刺目的少年。 \
　而且，除了那种罪恶感以外。 \
　最近我的胸口，还总是止不住地一阵阵发紧发疼。 \
　那是我人生里头一次尝到的疼。是在和她长久相处之前，连它的存在都不知道的疼。是直到我成了常盘孤太郎的替身，才第一次明白的疼。也是不管我去找多少代餐女人，都始终没有半点好转的疼。 \
　说到底，归根结底，就是这么回事。 \
　那个把原本作为我至高天堂而存在的羽切匣庭，却又轻而易举变成地狱的意外。那就是—— \
「……不行呢。明明以为自己已经想开了，可果然还是怎么都忍不住，会吃醋啊」 \
「……这样啊」 \
　──偏偏就是我，羽切臣虎，居然一不小心喜欢上了羽切菜摘。 \
　太不谨慎了。太蠢了。太自作自受了。也太晚了。 \
　可即便如此，我大概也只能继续在这里活下去。 \
　作为常盘孤太郎的替身。作为对常盘孤太郎的偿还。作为常盘孤太郎的基石。 \
　为了让常盘孤太郎今后也能继续在舒适的「箱庭」里，快快乐乐地讴歌人生。 \
　羽切臣虎大概也只能在这里，作为一名worker咬紧牙关活下去了。 \
「啊，对了！要是拿桌游当诱饵，说不定还有机会把你拐回我家呢，孤太郎！」 \
「……也许吧。要不等会儿我们再稍微把作战计划细化一下？」 \
「嗯。──真乖呢」 \
　──就在这座甜美得过分的地狱般的，羽切菜摘的匣庭里。
