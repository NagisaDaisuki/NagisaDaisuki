「啊……抱歉。果然还是得跟你把话说明白，番长。」 \
　米芙露小姐突然像一刀劈开圣诞派对的气氛似的，干脆利落地起了这个头，我和月乃小姐都一下愣住了。 \
　就在这时，她一个人重新把饮料放回桌上，站了起来。 \
　她踩着步子径直逼到我眼前近得不能再近。面对被她气势压住的我……米芙露小姐忽然低下了头。 \
「对不起，番长。」 \
「欸？为什么道歉？」 \
「就是之前我说过，我跟番长‘不过就只是玩乐关系而已’那件事。」 \
「啊、啊啊。那个啊，我倒也没怎么放在心上……」 \
「不是，伤到你是一回事啦。更重要的是，我说了那种谎，对不起。」 \
「谎……？」 \
「嗯。」 \
　这时抬起头来的米芙露小姐，脸上挂着的——是那种让我明白，这一次她说的真的没有半点掺假的、天真无邪的笑容。 \
「米芙露小姐……」 \
　总觉得像是隔了好久，才再次看到她那发自内心的笑。我刚松了口气，又不由得看得有些出神。 \
　而她就带着那种坏心眼得很有她风格的笑，继续把话说了下去。 \
「我啊，最喜欢番长了。」 \
「诶……」 \
　听到这句告白，我不由得倒吸了一口气。旁边一直看着事态发展的月乃小姐也是一样。心脏怦怦狂跳。被自己喜欢了好多年的人说喜欢自己。都这样了，还要我别飘，根本不可能。可是。即便如此。 \
　我看着月乃小姐那张透着不安的侧脸，又不知为何从她联想到了宇佐，好不容易才勉强找回了一点理智。 \
　我笑着接下了这位穿着圣诞装的辣妹同事的话。 \
「谢谢你，米芙露小姐。我也喜欢米芙露小姐哦」 \
「诶嘿嘿，谢啦。不过你这反应也太从容了吧，没劲死了」 \
「那不是当然的吗。平时就跟男朋友甜甜蜜蜜的米芙露小姐嘴里说出来的『喜欢』，怎么闻都只像是在给人下套，专门诱人误会啊」 \
「哇，好无聊。你搁这儿得意个什么劲啊，番长。真够臭屁的」 \
「托你的福」 \
　总算又找回了和米芙露小姐平时那种熟悉的对话节奏，我这才暗暗松了口气。 \
　对，就是这个。我喜欢的，一直都是这样。只要这样的日常还在，我就已经心满意足了。 \
「不过也是哦。虽然算我自作自受啦，但我说话的可信度，现在已经差不多跌到谷底了啊」 \
「是啊」 \
「不过呢。我超喜欢番长这件事，可是真的，没半点掺假哦」 \
「好好好，谢谢谢谢」 \
「你看吧！无聊死啦——」 \
　我们就这样彻底回到了平时那种亲昵随意的斗嘴节奏。转头一看，旁边的月乃小姐也正望着我和米芙露小姐的互动，微微笑着。 \
　啊，能回到这样的日常里，我真的幸福得不得了。 \
「啊，对了对了。那这样吧，我再多送你一个圣诞礼物，番长」 \
「啊？不是，你怎么突然——」 \
　而就在我还想像往常一样，随随便便把她这句耍宝敷衍过去的下一秒。 \
　——我的左脸颊上，忽然贴上了一抹柔软又湿润的触感。 \
『诶？』 \
　这突如其来的一幕，让我和月乃小姐都愣住了。……诶，等等。 \
　我刚才……是被米芙露小姐，亲了脸颊，吗？ \
　而且还是，出其不意地，像是和那次正好成了一对似的——落在了和那天摩天轮上相反的那边脸颊。 \
　…………。 \
　不，等等，这算什么。快工作啊，理性。对。这个说白了，也就是那种在国外不过只是打招呼的程度吧，就算她有男朋友，就算对象是同事，也没什么……！ \
「啊哈哈」 \
　看着陷入一片混乱的我，米芙露小姐乐得不行，捧着肚子笑了起来。 \
　她一边擦去大概是笑太狠才从眼角渗出来的泪花，一边又重新对我说道。 \
「圣诞快乐，番长！」
