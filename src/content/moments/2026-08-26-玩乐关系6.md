巽真理狭本人根本不在这里，那小鸟游米芙露到底是把什么错当成了她？ \
巽真理狭格外中意的那个业务合作对象，到底是谁来着？ \
那身玩偶服后来加上的功能──变声器，还有像被子一样软乎乎的绝佳手感，在这一幕里究竟是怎么发挥出最糟糕效果的。 \
番长今天的安排「暖烘烘地看家」，真正的含义。 \
以及，所谓「人这种东西，终究是靠所处的位置和穿着来决定身份」的那回事。 \
最后还有。 \
「啊，等等，不对尼夫不对尼夫！尼夫君不是巽真理狭尼夫啊！」 \
「啊哈哈，社长你还是一如既往地专业呢。我懂啦懂啦，尼夫君就是尼夫君嘛w」 \
「不对尼夫不对尼夫！」 \
从刚才起，她到底是在拼命地想干什么── \
──不，对，应该说「他」到底是在拼命辩解些什么「不是那个尼夫啦」。 \
「！」 \
意识到这一点的瞬间，我慌忙冲上楼梯。可无情的是，小鸟游小姐和他们的对话还在继续。 \
「然后，说正事啊，社长。」 \
「（等一下！）」 \
我本想这样喊出声，可突然拔腿狂奔、情绪剧烈动摇，再加上那该死的「恋爱宿醉」一起发作，嗓子哑得根本喊不出来！为什么偏偏挑这种时候啊！ \
我彻底放弃用声音阻止他们，转而拼尽全力朝事务所的门冲过去，借着那股冲劲一把推开门，然后── \
「我和小兔君那份伪装情侣契约，想今天就作废啦。」 \
──那个决定性「溃堤」的瞬间，就这样无比清晰地，硬生生摆在了我眼前。 \
「──诶？」 \
尼夫君发出一声错愕的惊呼。小鸟游小姐像是完全没弄懂他这反应是什么意思似的，微微歪了歪头。而我也只能像个傻子一样，呆呆杵在门口发愣。 \
就在这时。 \
「……刚才那样，确实有点像在偷听，这点我道歉。不过在那之前，你们两个。」 \
他一边把背后附近那道似乎不知何时已经改良过、如今能自己顺畅开合的拉链，发出「滋——」地一路拉开。 \
「……诶。」 \
直到这时才终于察觉到那「状况」，愕然僵住的小鸟游米芙露，就站在眼前。 \
尼夫君…… \
不。 \
脱下了「尼夫君」这层外壳的常盘孤太郎， \
希望、绝望、欲望、失望。 \
──仿佛把这一切都统统吞进了那抹笑里似的，脸上浮现出一个叫人根本看不透的微笑。 \
「能请你详细说给我听听吗？」 \
他就那样释放着仿佛匣庭新神降临般的压迫感，一步步朝我们逼了过来。 \
「关于那个荒唐的‘玩乐关系’。……你是乖孩子，对吧。」
