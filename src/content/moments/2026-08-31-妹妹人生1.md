所谓的命运，究竟是什么呢？ \
　例如说，要往左走还是往右走，这种选择不是一开始就决定好了，而是为了让我选择某一边，而事先安排好诱因。如此一来，就不会是「从一开始就全部决定好了」，而是让我误以为「自己选择了道路」，并继续走下去。 \
　假如。 \
　假如命运是如此决定的。 \
　说不定，我会在夏天的尾声看到妹妹的笑容，也是「被安排好的」。 \
在很久很久以后，我忽然想到这件事。 \
我以为，时间会一直像这样流逝下去。 \
　 \
　 \
　 \
时间是上午。虽然暑假所剩无几，但是今天还有一半没过。 \
　今年刚开通的大马路旁，地面还是裸露的土石。看不到道路的尽头，视野在上下左右无限延伸。仿佛要将那宽广无边的景色统整起来似地，天空的边缘缓缓地向上弯曲，形成穹顶。我们走在那样的乡间道路上。 \
　在伞的另一头，飞机飞过的声音拉出一条长长的线。 \
　平凡无奇的夏日光景。与我共享那灼热空气的，是血脉相连的妹妹。 \
　是啊。妹妹在家里，在同一个房间里。 \
「回家之后一起玩吧？」 \
　这是我第一次主动向妹妹提议。 \
　妹妹睁大了原本眯细的眼睛。似乎很意外我会这么说。 \
　可是过了一会儿，那惊讶有如被阳光融化似地消失无踪。 \
「哦，哦哦。」 \
　我不由自主地发出明显的动摇语气。 \
　伞在我手中，有如被风吹拂的花朵般不停转动。 \
　妹妹笑了。 \
　嘴唇微微弯起，眼角下垂。 \
　她笑了。那是我从来没看过的表情，使我大受冲击。 \
　脊椎滑稽地扭曲。 \
「哥哥——来玩吧——」 \
　妹妹第一次对我露出笑容。
