糖分烧焦的气味钻入鼻腔，没多久就渗入衣服与肌肤。 \
和我同期进公司，一起接受工厂说明的同事，眉头之所以皱在一起，应该也是因为这个气味的缘故吧。虽然还没自我介绍，但是我们已经以眼神充分沟通彼此的心情了。 \
目前在工作的人们，眉心与眉毛都没有皱起，我想我们很快就能适应了吧。同时，我也觉得那种眼睛的模糊感，是将来等着我们的事。不过我假装没看到。从今以后，我们每天都要被无法逃避的劳动束缚。 \
和学校那种想请假就能请假的课程不同，责任的重量截然不同。 \
我们已经不能逃避了。 \
四月，就职的第一天。我来到离公寓有一段距离的面包工厂，和其他新进员工一起学习作业。这比较接近新人研习的复习。除了我以外，还有许多一看就知道是上个月还是大学生的人。因为是学生时期才有的轮廓，所以特别显眼。 \
我也是其中之一吧。 \
在领队的中年员工说明之后，体验作业在等着我们。我们被带到把运来的面包烤或炸的加工作业现场。虽然被指导说直接碰到大型油炸机的话，可不是烫伤就能了事的，但我知道会怎么样。肉会被削掉。高中时代，我看过在汉堡店打工的朋友给我看被削掉的痕迹。在吃饭的时候。 \
我一开始想起这件事，在气味最重的地方一边听前辈的指示一边工作。机械运作的声音像墙壁一样逼近，有种两台洗衣机在脑袋旁边运转的压迫感。声音具有很大的力量。再加上气味和热气弥漫。毫无死角。 \
我本来以为能不怎么辛苦就找到工作，运气真好，但或许只是钻进了容易出现空隙的地方而已。 \
习惯之后，我感觉到自己在单调的作业重复中逐渐变得稀薄。 \
像晒干的纸一样，变得干巴巴的。 \
从干燥紧绷的身体中，连劳动的汗水都流不出来。 \
只是腐朽，碎片飞散而已。 \
午休可以在食堂自由用餐。虽说是自由，当然不是免费的。不过嘛，我早就觉得会有这种事，应该说这或许是约定俗成的吧，自家公司的面包可以吃到饱。虽然因为气味难闻，谁都不想碰就是了。 \
我坐在空着的椅子上，疲劳似乎更沉重地压在肩上。我感觉到身体的骨头有多重。平时潜藏在皮肉深处的重量渗了出来。绷紧的神经一放松，明明醒着却好像要打呼了。我忍住差点发出的呼噜声，端正姿势。 \
午休时间也不长。我开始吃起炸鸡套餐。味噌汤很浓，喉咙都快被烫伤了。 \
我比较喜欢老家，应该说妹妹的调味。 \
在我旁边一起吃饭的同期进公司的同事，比我还要阴沉。他义务性地把饭送进嘴里，吞下去后大叹一口气。他是个叹气很多的男人。他的态度就像在说，他对自己在这里这件事本身感到不满，想要申诉。因为会让喉咙不舒服，老实说我不太喜欢这种气氛。 \
那个同事不知道叹了第几口气的时候，我突然和他上下移动的视线对上。保持了一阵子沉默之后，他礼貌性地移动到我旁边的椅子。我有点紧张，以为他要跟我说话。 \
「嗨。」 \
「嗯。」 \
我们简短地交谈后，互相报上名字。虽然在进公司前的研修好像打过招呼，但我忘了。 \
「我第一天就想逃了。」 \
我含蓄地笑着同事的丧气话。虽然我并不想逃，但确实有想大叫「烦死了！」然后到处乱跑的心情。我忍住某种和郁闷不同的东西，让它在心里转来转去。这就是出社会吗？我切身体会到。 \
「真想快点离开这里。」 \
我对同事的这句感叹有点兴趣。 \
「离开之后要做什么？」 \
「做什么……你是自愿来这里的吗？」 \
他一脸意外地问我。「嗯。」我含糊地点点头。 \
「只要能糊口饭吃，去哪里都好。」 \
只要能这样支持妹妹，我就满足了。 \
这样就够了。 \
「哦——真是个没有梦想的家伙。」 \
「是啊。」 \
「那也很令人羡慕。」 \
他似乎不是在挖苦我。他趴在桌上，玩弄着下唇。 \
「我想成为小说家。」 \
「哦。」 \
炸鸡块是鸡胸肉，不知道是不是炸太久了，有点干干的，感觉塞牙。 \
还以为他要转职到其他地方，原来他怀抱着有点远大的梦想。 \
「在学期间没能成为小说家，所以只好先就业。」 \
「哦……」 \
我觉得这是常有的事。大部分的事情都不会如人所愿。 \
因为世界在我们的脑袋外面，所以这是理所当然的。 \
不过，要决定要不要接受这个世界的是我们的脑袋。 \
只有能接受的人，才能接受眼前的现实。 \
「人生就是不能随心所欲地活着啊。」 \
「……我也有意识到这一点。」 \
无论大小，我们都是追逐着愿望这个光芒度过人生。
