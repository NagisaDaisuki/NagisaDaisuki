颁奖典礼当天，我理所当然地照常在工厂里工作。尽管妹妹露出希望我陪她去东京的表情，可是我不能丢下工作不管。 \
　……不，不对，不是这样的。 \
　其实，我大可以请假的。 \
　明明可以请假，我却没有那么做。 \
　为什么我没有陪妹妹去东京呢？类似赌气，类似惰性，绝非积极正面的念头与想法在我心中打转。负面情绪束缚着内脏，呼吸中混杂着胃液的味道。 \
　我放空脑袋工作，时不时地喃喃自语。 \
「东京啊……」 \
　妹妹现在，正一个人待在那个只在电视中看过的都会里。 \
　妹妹走在自己前方的感觉，仿佛喝醉般摇晃着我的五脏六腑。 \
　现在，颁奖典礼应该正在进行吧？ \
　妹妹的头顶上，有过度的照明。以及，如彩虹般扩散的，梦想。 \
　对于在生活这棵树上扎根太久的我来说，那些事物都太遥远了。 \
　工作告一段落，午休时间。我仰望天花板。 \
　不管再怎么凝视工厂的天花板，我也只能看到单调的色彩，看不到梦想。 \
不展翅飞翔的鸟儿，会觉得幸福吗？ \
　就算能活下去，也不会觉得不自由吗？ \
　假如妹妹一直当个坐在哥哥背上的妹妹，就等于扼杀了某种才能的嫩芽。所以，假如妹妹能因此展翅高飞，那绝对是正确的。 \
　假如才能能因此在世界上循环，不再淤积，一定能被许多人接受。 \
　身为人类，身为哥哥，我确定这是正确的选择。 \
　可是，那只是正确而已。我只会因此失去。 \
　正确不会拯救我。 \
光是想象，胃就抽痛了起来。空腹与压力使我备受煎熬。 \
　心情之所以如此沉重，没有吃晚餐应该也是原因之一吧。 \
　在身心被消耗到再也动不了之前，必须先斩断恶性循环才行。 \
　我无奈地换上外出服，走出家门。头发还没干，我只带着钱包，独自出门。 \
　夜晚的空气冷到让人不想呼吸，钻入身体的中心。 \
　为什么我要出门呢？我马上就后悔了。 \
　如果现在下雪的话，虽然会冷到快死掉，但是至少有气氛。可惜的是，现在是云不多的夜晚，没有云的话，天空就没有深度。就算抬头仰望，心情也不会变好。 \
　走在路上，我有种身体从膝盖开始逐渐崩解的错觉。肉体化为丝线，无力地从身体脱落。我累了，想睡，肚子饿了。没有余力承受这三重痛苦之外的心劳，难以维持自我。 \
　我不想改变什么。 \
　应该说，我希望某些事物不要改变。 \
　妹妹也是，才三个月的同事也是。 \
　我完全不羡慕那些实现梦想的人。 \
　我有我的生活方式。鸟和人住的地方不同，没有优劣之分。 \
　但是，那种生活方式的根基正在动摇。现在还只是小小的裂缝。 \
　可是我有预感，裂缝会逐渐扩大。 \
　今后，差异会变得更大。 \
　虽然我这种人别说明天了，就连五分钟后的未来都无法预测，但是却能隐约感觉到某种趋势，是种很麻烦的生物。我感觉得到，自己身处的洪流中，有某种阴影。如果能更愚钝一点，对任何事都浑然不觉地活着，该有多幸福啊。 \
　我经过地铁的入口，仿佛忘了该去哪里似地继续走着。 \
　呼出的气息，感觉很沉重。 \
　每往前走一步，就变得更弱。我再也无法抗拒软弱的心灵的倾诉。 \
　经过便利商店时，巧克力的图画不由分说地进入我的视野。 \
　不知为何，过剩的明亮灯光，强烈地打击着我。 \
　最后，我连呼吸都变得困难，再也无法忍受。 \
　肉体崩解后留下的真心话，暴露出来。 \
　我承认。 \
　我，喜欢软弱的妹妹。 \
　而且，被那样的妹妹依赖，让我觉得自己很重要。 \
　真是简单易懂。 \
　我所期望的，并不是成为小说家的妹妹，而是支持着想成为小说家的妹妹的状况。 \
「啊啊啊啊啊。」 \
　我忍不住发出丢脸的声音，用手遮住脸。完全不在乎路人的眼光。 \
　虽然没有流泪，但是对自己的可耻、丢脸……没用，这些情绪无法抑制地满溢而出。到这个年纪为止，我只有这个。从小建立起来的只有这个，没有其他。我已经走到无法回头的地步了。 \
　我，哪里都去不了。 \
　只能待在这里。 \
　待在这里的理由，正在剥落。 \
　失去这个理由时，我还会剩下什么？ \
　只有无法累积每个人都能平等获得的事物，这个事实吗？ \
　只剩下时间的残骸吗？ \
　这种消极的心情，让我逃避似地别过脸。 \
　或者，这其实是引导我的力量。 \
　夜晚与汽车的味道冰冷地吹过，前方。 \
　隔着马路的对面人行道上，我看到怀念的脸孔。 \
　我倒抽一口气。 \
　她，一个人走着。 \
　我连呼吸都忘了，停下脚步，看得入神。 \
　简直像妹妹换了个模样出现，我甚至觉得这是不是太巧了。说不定是幻觉。毕竟已经好几年没见了，一眼就认出她也很奇怪。 \
　再说，她从大学毕业之后，是不是住在附近……总之，事情发生得太凑巧了。如果是因为内心空虚而产生的幻觉，我还能理解。她看也不看我一眼，往反方向走去。我呆立在原地，只能用眼睛追着她，双脚动弹不得。 \
　要追上去吗？我一直在考虑。 \
　我不知道追上去之后要做什么。 \
　但是，说不定能填补什么。 \
　这种自私的动机，几乎要失控了。 \
　可是，已经。 \
　要抓住其他东西，已经太迟了。 \
　我无法回头，走回自己的路上。 \
　结果，我只能沉默地目送那幻影般的她离去。 \
「………………………………………」 \
　是谁说过的话呢？ \
　感觉到孤独，代表得到正常的认知。 \
　人类的本质是孤独。 \
　但是，接近真理不一定能发现幸福。 \
　人类需要名为幸福的错觉。为此，人类互相依偎着活下去。 \
　我记得，有人说过这些话。 \
　不知道是谁发现的这个真理，究竟有没有后续呢？ \
　我。 \
　我。 \
　我。 \
「算了，无所谓。」 \
　我笑了。 \
　笑到肩膀发抖。 \
　明年，我将迈入三十岁。 \
　其实我到现在还是处男。 \
不是说要将一生奉献给某人或什么的。人生不管走到哪里，都只是自己的东西，所以不管做出什么选择，不管得到多少快乐，不管背负多少重担，全都是我得到的。 \
　所以，只要妹妹笑得很开心，大部分的事情我都能觉得「算了，无所谓」，也是因为这种生活方式吧。而我花了很长的时间，才发现这种粗心大意的轻松，会左右自己的一生。发现的时候，世界已经建构完成，无法再做任何改变，我们只能这样活下去。 \
　就算失去名为年轻的幻想，双脚着地。
